## 1. 引言/概述

AI 造价师是辅助专业造价师完成**资料理解、清单核对、成本测算与报价协作**的业务产品，首个落地品类为**电气桥架**。

当前造价师的痛点：报价不是“数量乘单价”，而是要从清单、图纸或口头描述中整理需求，核对同物异名，确定执行标准与工艺参数，再按企业价格测算成本。全过程依赖人工搬运和 Excel 经验，耗时、易漏项、难复核、难追溯。

MVP 用**有限物料（钢板、槽式直通、200×100 规格为主）加 2–3 种计价规则**跑通最小业务闭环：

```text
上传清单/图纸 → AI 辅助解析 → 匹配标准物料 → 造价师确认标准清单
→ 计算引擎双成本测算 → 版本快照与追溯 → 对外报价单 → 导出交付
```

**人机分工**：AI 负责理解资料、匹配物料、提示差异、起草澄清话术；**金额一律由确定性计算引擎按已确认的规则与数据产出**；资料歧义、非标判断、清单确认和最终报价由造价师决策。

## 2. 目标

- 跑通“资料解析 → 标准清单确认 → 双成本测算 → 对外报价”完整链路，造价师可在一单询价中全程使用。
- 提供五类数据资产（标准物料、执行标准、工艺规则、企业价格、市场价格）的人工维护；项目引用时保存当次快照。
- 双成本并列展示：标准参数成本（基准）和实际生产成本（经营参考），支持调参重算并对比版本差异。
- 每次测算保存完整快照（价格、标准、公式、参数、人工调整），历史结果不随库内数据更新而改变。
- 图纸解析深度**仅到物料属性**，不做自动算量和图元定位。
- 单一角色（造价师）加基础登录即可用，不建设复杂角色权限。

**描述：**作为造价师，我希望把成本测算结果导出为 Excel，以便内部复核和存档。

- [ ] 导出内容包含版本号、测算时间、关键依据说明，与已保存快照一致。
- [ ] 双成本标记为内部资料，不在对外报价单中默认展示。
- [ ] 导出单元格防公式注入，金额不丢精度。
- [ ] 工程检查通过。

### US-018：对外报价单
**描述：**作为造价师，我希望引用已确认的成本版本，填写定价与商务条件后生成对客报价并导出，以便完成交付。
- [ ] 项目下可创建对外报价单，必须引用一个已确认或已冻结的成本版本。
- [ ] 支持填写定价方式（加价率或毛利率，两者不混用）、费用、税费、商务条件。
- [ ] 按定价参数计算对客价格；运费、税费重复计入时给出校验提示。
- [ ] 生成报价草稿，造价师确认后导出 Excel 和 PDF；不建设多角色审批流。
- [ ] 修改已确认报价生成新版本并保留修订记录；后续成本重算不自动覆盖历史报价。
- [ ] 对外报价单不展示内部成本明细。
- [ ] 工程检查通过，并在浏览器核验。

### US-019：端到端测试：询价到报价全链路
**描述：**作为 QA 工程师，我希望有自动化 E2E 覆盖从建项目到导出报价的完整旅程，以便跨层回归。
- [ ] 模拟完整 happy path：登录 → 初始化数据资产（物料、标准规则、工艺公式、价格）→ 建项目 → 建成本报价单 → 上传清单和图纸 → 解析 → 匹配确认标准清单 → 双成本测算 → 冻结版本 → 创建对外报价单 → 定价 → 导出，断言每步可见结果。
- [ ] 视觉模型在 CI 中使用受控响应，并显式标注；真实模型质量另行报告。
- [ ] 覆盖关键失败路径：缺价物料测算被阻断；未确认清单不允许测算；偏差超限被阻断。
- [ ] 覆盖快照正确性：修改价格库后，历史冻结版本金额不变。
- [ ] 在 CI 运行并通过，独立可重复（自行构造和清理数据、容器与命名卷）。

## 4. 功能需求

**登录与基础**
- FR-1：系统必须提供账号密码登录，未认证访问业务页面或 API 一律拒绝。
- FR-2：系统必须为造价师提供工作台首页，展示其项目列表、进度阶段与待办事项。

**数据资产中心**
- FR-3：系统必须支持标准物料的增删改查、停用与 Excel 批量导入，物料含分类、材质、规格、单位、别名。
- FR-4：系统必须支持标准文档登记与标准规则的人工录入，规则包含适用条件、参数值、单位与原文出处。
- FR-5：系统必须将标准规则区分为“待确认/已确认”，仅已确认规则参与自动测算。
- FR-6：系统必须支持工艺规则的维护：适用条件、参数、公式、版本，并提供样例试算。
- FR-7：系统必须支持企业价格的维护与价格历史（多供应商、含税口径、生效日期）。
- FR-8：系统必须支持市场参考价的维护与企业价对照展示，且市场价不自动参与测算。
- FR-9：当项目引用任一数据资产时，系统必须保存当次快照，资产后续更新不得改写历史项目结果。

**报价项目**
- FR-10：系统必须支持项目的创建、编辑、结束与需求变更重开，重开不得覆盖已确认历史。
- FR-11：一个项目必须支持关联多份单据；一份单据必须支持多个版本。

**成本报价单**
- FR-12：系统必须支持上传材料清单（Excel/PDF）与图纸，解析失败必须明确提示。
- FR-13：系统必须将清单解析为带来源位置的候选条目；图纸经视觉模型仅产出物料属性候选，数量为“待核实”。
- FR-14：系统必须将候选条目与标准物料库自动匹配，并区分精确、模糊、库外三类结果。
- FR-15：当清单与图纸两路资料同时存在时，系统必须提供比对视图。
- FR-16：系统必须集中呈现缺项、冲突、疑似重复与库外物料，并支持修正、补录、合并、非标标记。
- FR-17：存在未解决关键缺项时，系统必须阻断清单确认。
- FR-18：系统必须支持生成对客澄清单，AI 起草话术，造价师编辑、记录答复并回填条目状态。
- FR-19：系统必须基于已确认清单、已确认标准规则、工艺公式与企业价格执行确定性计算，产出标准参数成本与实际生产成本两套结果。
- FR-20：系统必须校验实际生产参数满足适用标准允许偏差，不满足时阻断。
- FR-21：缺少计算条件的清单行必须明确标记原因，不得静默以零值参与合计。
- FR-22：系统必须支持调参、切标准、引新价重算，生成新版本并保留旧版本，提供版本差异对比。
- FR-23：人工调整金额必须记录原因并留痕，且不得绕过强制约束。
- FR-24：系统必须保存每个成本版本的完整快照（清单版本、规则版本、公式版本、取价、参数、调整、操作人、时间）。
- FR-25：系统必须支持冻结成本版本，冻结后只读。
- FR-26：系统必须支持成本结果导出 Excel。

**对外报价单**
- FR-27：对外报价单必须引用一个已确认或已冻结的成本版本。
- FR-28：系统必须支持定价参数（加价率/毛利率二选一）、费用、税费与商务条件填写，并计算对客价格。
- FR-29：系统必须对运费、税费重复计入给出校验提示。
- FR-30：报价确认后必须支持导出；修改已确认报价必须生成新版本并保留修订记录。
- FR-31：对外报价单不得展示内部成本明细。

## 5. 非目标

- 独立的 AI 报价助手（聊天入口），后续迭代。业务页面内嵌的解析、匹配、澄清话术等 AI 能力不在此排除。B 不挂载 Core 的自然语言报价任务入口。
- 图纸**自动算量**与**图元定位/回溯**。MVP 只做物料属性解析。
- 执行标准规则的 **AI 自动提取**。人工梳理确认后手工维护；B 不使用 Core 的规则候选生成来产出执行标准。
- 外部行情**自动接入**。市场价格手工维护。
- 多角色（数据维护员、审核、管理者）与复杂权限。只有造价师单角色加基础登录。
- 对外报价的多级审批流。造价师确认即可。
- 任意新算法的自助配置。只实现约定的 2–3 种计价规则。
- 桥架以外的产品品类；管理分析视图、经营报表。
- 外部系统（ERP、行情源、IM 渠道）集成，包括客户自有报价函数接入。
- 自动对外发送报价或澄清单。

## 6. 设计考虑

- 页面布局与交互**参考 Blueprint OS**（客户已沟通确认的页面范围），业务规则以客户确认结果为准。
- 成本报价单是核心页面：资料 → 候选 → 标准清单 → 双成本 → 版本，应在一单内连贯完成，减少跨页跳转。
- 差异集中呈现优于分散提示：缺项、冲突、库外、疑似重复统一面板处理。
- 双成本并排对比是核心视觉：两套参数、两套金额、差异高亮。
- 所有 AI 产出（解析结果、匹配建议、澄清话术）明确标记为**待确认**，与人工确认内容区分。
- 造价页面通过 Core 的 `FrontendScenarioModule` 挂载；公共框架不按行业名称分支。

### 7.4 其他约束

- **计算引擎与 AI 解耦**：金额计算为纯确定性服务，输入为已确认数据与规则版本，可独立测试；不复制被测算法生成测试预期。
- **快照模式**：成本版本依赖的规则、价格、公式按值快照。
- AI 能力（清单解析、图纸视觉识别、物料匹配、话术起草）通过受控业务接口嵌入页面，不直接写库；模型输出一律作为不可信数据校验。
- 数据保密：外部模型或视觉模型的使用遵守与客户的保密约定；未获许可的文件不外发，并在页面显示原因（V03-049）。
- 数量与金额保留精确表示及明确单位、币种；舍入阶段与口径经客户确认。
- 文件大小、页数、行数、模型并发和超时有界；截断显式不完整。

## 8. 成功指标

- 造价师使用 MVP 完成一单完整询价（含补录与复核）的总工时 **≤ 现有人工方式的 50%**（以真实样本对比衡量）。
- 标准清单确认前，AI 解析与匹配的物料识别**人工修正率可被度量**（目标在试点中逐步降低）；图纸视觉解析单独统计。
- 双成本测算结果与客户人工计算案例**逐项核对一致**（2–3 种计价规则全部案例通过）。
- 任一历史成本版本可完整还原计算依据，“这次与上次差在哪里”可在版本对比页直接回答。
- 冻结版本在价格或规则更新后**金额不变**（快照正确性 100%）。

内部合成验证、真实样本核对和客户试点验收分别记录，未达到的层级显示实际状态。
