# 电气桥架造价：竞品调研与可借鉴点

> 日期：2026-09-30｜用途：竞品基线、产品/本体设计借鉴、给其他 Agent 的输入
> 说明：厂商自述能力（如"准确率 98%"）为**宣传口径，未独立验证**；本文标注来源，供参考不对赌。

---

## 0. 一句话

竞品分四类：**国产造价软件（广联达/品茗/鲁班/晨曦）**、**国际算量（Trimble/Togal/Kreo/Bluebeam）**、**电气垂直报价（桥架/母线/电缆厂家工具）**、**非标制造报价**。它们的共性能力是 **"AI 识图 → 自动建模/提量 → 套价/组价 → 清标审核"**。**本项目所处的是"供应商/厂家报价"长尾，正是这些巨头覆盖最弱的地方。**

- 桥架/母线槽/电缆厂家报价软件；非标钣金自动报价工具。
- 特征：**展开面积/重量 → 吨价成本 → 报价**（与客户 Blueprint OS 同类）。
- 现状：多为**规则固定、无 AI、不做图纸**的报价表工具；**AI 化程度低**。

## 2. 竞品的共性能力链（值得对照）
```
AI 识图（CAD/PDF/图片）
  → 自动建模 / 构件识别 / 符号计数
  → 自动提量（联动更新、一量多用）
  → 套定额/清单 → 智能组价
  → 智能清标 / AI 审核 / 指标分析
  → 数据资产沉淀（材料价、指标）回流工具
  → 数字新成本 / 全过程咨询
```

---

## 3. 可借鉴点（映射到本项目）

| # | 竞品做法 | 借鉴到本项目 |
|---|---|---|
| 1 | **智能识图→提量→组价一条链** | 你的链：`清单/图纸 → 展开面积/重量 → 成本 → 报价`（供应商版） |
| 2 | **规则库（清单/定额/地方规则）**，可配置 | 造价规则做成**可配置 + 版本化（含地方差异）** → `industry-packs` 规则 + 价格版本 |
| 3 | **端侧数据上云成资产，再回流工具**（品茗） | 把**历史报价 + 价格参数**沉淀为数据资产，回流到新报价 |
| 4 | **智能组价 / 智能清标 / AI 审核** | 你的 `规则求值 + 冲突检测 + 硬核验`（清标=核验，天生对口）|
| 5 | **PDF/无框识别（不依赖图层）**（品茗）+ **CAD 识别**（广联达）| 你的图纸策略 **L3(导出)/L2(DXF)/L1(图层文字) + PDF fallback** |
| 6 | **量价联动 / 一量多用**（模型改→提量刷新）| 你的**版本 diff + 证据绑定**（改输入→重算→保留前后差异）|
| 7 | **自然语言查历史价/参数**（Trimble 助手）| 你的**报价助手**（受控、带证据）|
| 8 | **指标分析控误差、降争议**（品茗）| 你的"金标准比对 + 差异归因"（解析/标准化/规则/价格/人工哪一类错）|
| 9 | **符号识别/计数**（Trimble MEP）| 桥架附件/弯通/支架/接地符号计数（若图纸进 MVP）|

## 4. 差异化与"不竞争区"

**竞品不做 / 做不好的：**
1. **领域**：广联达/品茗是**土建/安装工程算量+清单计价**；本项目是**电气桥架厂家报价**（展开面积→吨价），属**长尾**。
2. **计价口径**：竞品按"定额+综合单价"；你按"重量×吨价+加工/表面处理+配件+运费+系数"——**两套体系**。
3. **可追溯/证据**：竞品的"AI 识别"多为黑盒结果；你的差异点是**逐项证据 + 硬核验 + 双时态 + 撤回**（这是 core 的强项）。
4. **轻量/垂直**：竞品是大而全平台；你的机会是**垂直、可解释、能复核**的桥架报价。

**不要做（避免以卵击石）：**
- 不要追求广联达式的"全专业大平台"；
- 不要在没有人工核量结果时死磕"图纸全自动算量准确率"；
- 不要自建定额库（可直接对接/参考现有厂商数据）。

---

## 5. 对本项目本体/产品的启示

1. **本体重点**：把"规则库"建模为**可配置、版本化、含地方的规则实例**（不是写死代码）——直接对应竞品的护城河。
2. **数据资产**：历史报价 + 价格参数 = 你的"结果真值 + 计算真值"，要做成**可回流、可评测**的资产。
3. **清标/核验**：把 `verify_result` 当作**"智能清标"**来卖——量价一致、规格冲突、缺项、超范围。
4. **图纸分级**：明确 **L1/L2/L3 + PDF fallback**，并诚实标注可稳定抽取项/不可抽取项（对齐 `costing-master` 的 dwg-cad-handling 策略）。
5. **交互**：参考"量价联动、一量多用、差异对比"，做成"改输入→重算→差异与原因 trace"。

---

## 6. 结论
- 竞品把"**AI 识图 → 提量 → 组价 → 清标**"做成了成熟链条，**可直接借鉴其能力清单与交互**；
- 但**电气桥架厂家报价**是它们覆盖薄弱的长尾，**你的差异化 = 垂直 + 可追溯 + 可核验**；
- **借鉴"能力与规则库形态"，不要照搬"大平台广度"**。
