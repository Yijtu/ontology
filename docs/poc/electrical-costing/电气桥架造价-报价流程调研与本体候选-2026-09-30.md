## 0. 一句话

**"桥架报价"其实有两套完全不同的流程**：一套是**供应商/制造厂按"展开面积→重量→吨价"算成本**（客户 Blueprint OS 就是这套），另一套是**工程造价咨询按"清单计价规范"算量组价**。本项目服务的是**第一套（供应商报价）**。下文先讲清两套，再落到桥架的公式、黄金算例和可抽取的本体候选。

---

## 1. 两种"造价师"报价流程

### 1.1 供应商 / 制造厂报价流程（= 客户的流程，本项目主战场）
```
收到询价清单（客户图纸+清单）
  → 识图/读清单：确定桥架型号(槽式/梯式/托盘)、宽×高、板厚、材质、表面处理、数量、附件、交货地
  → 补齐/标准化：统一命名、规格、单位
  → 算工程量与重量：展开面积法算每米重量 → 乘米数得总重
  → 算成本：材料费(板材吨价) + 表面处理费(镀锌/喷塑/防火) + 加工费 + 配件 + 其它 + 运费
  → 加商务：利润 / 报价系数 / 税
  → 生成报价单（按米/件/吨）→ 复核 → 对外报价
```

特征：
- **核心是"重量 × 吨价 + 加工/表面处理/配件 + 运费"**，按**米**或**件**报价；
- 价格来自**板材行情 + 表面处理单价 + 加工费**，而非工程定额；
- 依赖**展开面积、密度、板厚、折边**等制造参数；
- **Blueprint OS 就是这套**（原型里能找到展开宽度公式、密度 7.86、加工费、配件 5.1 元/m）。

### 1.2 工程清单计价流程（GB 50500，造价咨询/施工投标）
```
熟悉图纸与规范
  → 计算工程量（按规范计量规则）
  → 编制工程量清单（项目编码/名称/特征/单位/工程量）
  → 询价 / 套定额（人材机消耗量）
  → 组综合单价（人工+材料+机械+管理费+利润）
  → 计取措施费、其他项目费、规费、税金
  → 汇总形成招标控制价 / 投标报价
  → 复核 → 报审 / 投标
```

特征：
- 按**清单计价规范**，工程量单位常为 **m、个、套、kg、m²**；
- 综合单价 = 人工 + 材料 + 机械 + 管理费 + 利润（不含规费税金）；
- 桥架**安装**通常按定额子目（如"桥架安装 100m"）计人工机械，**主材另计**；
- 这是"造价师"更标准的语境，但**不是客户 Blueprint OS 在做的事**。

### 1.3 本项目定位（重要）
| 维度 | 供应商报价（客户现状）| 清单计价（造价咨询）|
|---|---|---|
| 计价基础 | 展开面积 → 重量 → 吨价 | 定额 + 市场价 → 综合单价 |
| 报价单位 | 米 / 件 | m / 个 / kg / m² |
| 关键参数 | 宽高厚、折边、密度、表面处理、加工费 | 工程量、定额子目、人材机单价 |
| 客户系统 | ✅ Blueprint OS | ❌ 未涉及 |

**结论：MVP 对齐"供应商报价流程"**；清单计价可作为第二期扩展（若客户同时做工程投标）。

## 2. 电缆桥架计量规则（行业惯例，供本体建模参考）

来源：公开造价资料（知乎《电缆桥架计量规则及安装工程量计算》、百度文库《桥架计算规则与价格计算方法》、GB 50303《建筑电气工程施工质量验收规范》）。

- **桥架本体**：按设计图示尺寸以**长度（m）**计算；弯通、三通、四通、变径等按**个**计或用当量米折算。
- **附件**：连接片、螺栓、锁扣、接地跨接线按**米/组/套/个**计量（随桥架及接头数量变化）。
- **支架**：按 GB 50303，**水平桥架支架间距 1.5–3 m，垂直桥架支架间距 ≤ 2 m** → 可由桥架长度**估算支架数量**。
- **防腐/刷油/防火**：单独列项（桥架刷油、防火涂料）。
- **计量要点**：不扣除小范围孔洞；跨图/断线/重叠的路径要接续计算。

> 待确认：本项目的**自动报价范围**是否含支架、刷油、防火、接地，还是仅桥架本体 + 明确附件。

## 3. 桥架重量与成本公式（从客户原型 + 样例提取）

### 3.1 展开面积法（核心）
```
槽体每米展开(mm) = 宽 + 2×高 + 2×折边
盖板每米展开(mm) = 宽 + 2×折边
隔板每米展开(mm) = 高 + 2×折边
```
> 客户样例用**折边 = 15 mm**；原型 UI 有"单侧折边余量"参数（默认值待确认）。

### 3.2 每米重量
```
每米重量(kg/m) = 展开(mm)/1000 × 密度 × 厚度(mm)
梯档重量       = 按「档距 mm、梯档厚度 mm」折算
总重(kg)      = Σ(每米重量) × 长度(m) × (1 + 损耗%)
```

### 3.3 每米成本（供应商口径）
```
每米成本 = Σ [ 厚度×展开×密度 ] × (板材吨价 + 表面处理吨价 + 加工费吨价)
         + 配件(元/m) + 其它(元/m)
报价成本 = 每米成本 × 米数 + 运费
```
（样例中"板材+表面处理+加工"以**元/吨**给出，重量以 kg 计，故折算为千元/吨。）

### 3.4 客户原型里的常量（待确认）
| 参数 | 值 | 来源 |
|---|---|---|
| 密度 density | **7.86** | 原型配置 / 报价流程 docx |
| 密度常量 Cm | **7.85** | 原型 JS 常量（**与 7.86 冲突！**公开资料多为 7.85）|
| 配件 accessoryYuanPerM | 5.1 元/m | 原型 / 样例 |
| 其它 otherYuanPerM | 2.2 元/m | 原型 / 样例 |
| 重量取整 weightRounding | 向上（ceil）| 原型 |
| 税率 taxRate | 13% | 原型 |
| 梯档 | 加强={重量0.22,价10.8}；否则={重量0.14,价6.8} | 原型 |
| 加工费 | 500 元/吨 | 报价流程 docx |
| 板材价 | 1.2厚=4800元/吨；1.0厚=4900元/吨 | 报价流程 docx（**时效未标**）|
| 表面处理 | 1.2厚=7000元/吨；1.0厚=7200元/吨 | 报价流程 docx（**时效未标**）|
| 运费 | 单车 800 元 | 样例 |
| 报价系数 | 1.02 | 报价表 .xls |

### 3.5 价格参数表（报价表 .xls 提取，待客户确认时效）
- **板厚分档**（宽 → 本体厚/盖板厚）：宽<150→1.0/0.8；150≤宽<300→1.2/1.0；300≤宽<500→1.5/1.2；500≤宽<800→2.0/1.5；宽≥800→2.2/2.0
- **高度分档**：高<150→4.0；高<250→8.0；高<250→12.0
- **异形件价**：水平弯通、垂直弯通、三通、四通、终端封头（分规格）
- **附件价/米**：连接片、螺栓、接地线、隔板、盖板等

## 4. 黄金算例（可作验收基线）

**输入**：300×200 热浸镀锌板槽式桥架，180 m，带盖，JB/T 10216-2013，槽厚 1.2、盖厚 1.0，货到南通。

```
槽体展开 = 300 + 2×200 + 2×15 = 730
盖板展开 = 300 + 2×15 = 330
槽体+盖板每米 = 1.2×0.73×1×7.86×(4.8+7+0.5) + 1.0×0.33×1×7.86×(4.9+7.2+0.5)
              = 117.37 元
配件 5.1 + 其它 2.2 → 每米成本 124.67 元
成本 = 124.67 × 180 = 22440.6 元
重量 = (1.2×0.73 + 1.0×0.33) × 7.86 × 180 ≈ 1707 kg
+ 运费 800 → 报价成本 23240.6 元
```
> 该算例来自客户"报价流程.docx"，可直接作为**计算引擎的第一个验收用例**（复算到 117.37 / 124.67 / 22440.6 / 1707）。

## 5. 本体候选 v0.1（`industry-packs/electrical-costing` 起点）

### 5.1 对象（Object Types）
| 对象 | 说明 |
|---|---|
| `CableTray`（桥架直线段）| 槽式/梯式/托盘式 |
| `Accessory`（配件）| 弯通、三通、四通、变径、终端封头、隔板、盖板 |
| `Fastener`（紧固/接地件）| 连接片、螺栓、锁扣、接地跨接线 |
| `Bracket`（支架）| 按 GB50303 间距估算 |
| `Material`（材质/板材）| 钢、镀锌板、不锈钢、铝合金… |
| `SurfaceTreatment`（表面处理）| 热镀锌、喷塑、防火、耐腐蚀等级 |
| `Quote`（报价结果）| 每米成本、总价、成本构成 |

### 5.2 属性（Attributes）
宽、高、长/米数、板厚(本体/盖板)、折边余量、材质、表面处理、耐腐蚀等级、标准、数量/单位、交货地、税口径、损耗率、报价系数。

### 5.3 关系（Relations）
- `CableTray` —按需包含→ `Accessory` / `Fastener`
- `CableTray` —使用→ `Material` / `SurfaceTreatment`
- `SurfaceTreatment` —适用于→ `Material`
- `Quote` —由…组成→ 材料/表面处理/加工/配件/其它/运费

### 5.4 规则（Rules，受控子集 + 例外）
| 规则 | 内容 | 状态 |
|---|---|---|
| 展开宽度 | 槽体=宽+2×高+2×折边；盖板=宽+2×折边 | 原型已实现，待确认 |
| 板厚分档 | 按宽分档自动选本体/盖板厚 | 样例支持，待确认 |
| 客户指定优先 | 客户明确指定板厚时覆盖分档 | 待确认 |
| 标准节长 | 3m/节 → 米↔节换算 | 样例支持，待确认是否全局 |
| 盖板配置 | 项目备注可规定全部配盖、材质一致 | 已见样例，项目级 |
| 附件配置 | 连接片/螺栓/锁扣/接地线随桥架/接头变化 | 待确认 |
| 材质-工艺兼容 | 热镀锌/喷塑/防火/耐腐蚀的适用关系 | 待确认 |
| 成本构成 | 材料+表面处理+加工+配件+其它+运费 | 框架明确，公式待确认 |
| 商务计算 | ×利润/系数/税 | 框架明确，顺序/基数待确认 |
| 冲突/缺失处理 | 多值不一致或必填缺失 → 阻断/澄清 | MVP 强制原则 |

### 5.5 计算操作（`extensions/electrical-costing` → `costing.quote`）
确定性、版本化、可逐步复算：
```
展开宽度(宽,高,折边)
每米重量(展开,密度,厚度)
每米成本(重量, 板材价, 表面处理价, 加工费) + 配件 + 其它
报价(成本, 系数, 税, 运费)
```

## 6. 流程中的分工（AI / 确定性 / 人工）

| 环节 | AI（LLM）| 确定性引擎 | 人工 |
|---|---|---|---|
| 读清单/图纸→参数 | ✅ 提候选（含置信/来源）| — | 确认/修正 |
| 标准化/同义词 | ✅ 提映射候选 | ✅ 词典匹配 | 确认非标 |
| 展开/重量/成本/报价 | ❌ | ✅ 公式计算 | — |
| 板厚分档/客户指定 | ❌ | ✅ 规则求值 | 对非标选择 |
| 缺失/冲突 | ❌ | ✅ 检测 | 澄清/阻断 |
| 金额 | ❌ 绝不生成 | ✅ 唯一来源 | 复核 |
| 输出/追溯 | — | ✅ 证据绑定 | 审批 |

**原则**：LLM 只做"理解/候选/解释"，**金额与规则结论一律确定性引擎算**，人工处理不确定性并负责。

## 7. 待客户/造价师确认的口径（必须逐项确认）

1. **密度**：7.85 还是 7.86？不同材质是否不同？
2. **折边余量**：默认 15mm？按产品/板厚区分？
3. **单位**：厚度按 mm、展开按 m 的"数值技巧"要不要固化统一单位？
4. **重量取整**：向上取整？保留几位？
5. **损耗率**：默认值？分产品？
6. **税率/税口径**：13%？含税/未税报价口径？
7. **价格时效**：板材/表面处理/加工费/配件**基准日**与有效期？
8. **板厚分档表**：以客户确认版为准。
9. **报价系数/利润**：1.02？还是按项目？
10. **范围**：是否含支架、刷油、防火、接地？异形件按个还是当量米？
11. **节长换算**：3m/节是否全局？
12. **xls 异常**：报价表中的异常公式 / `#VALUE!` 以哪个为准？
