# V03-056：实现物料匹配、差异集中与标准清单确认服务

阶段 B · backend · P1 · 状态 planned · GitHub [#224](https://github.com/Yijtu/ontology/issues/224)

执行工作线：feat/electrical-costing-poc；目标：feat/electrical-costing-poc。2026-10-14 按 [新 B PRD](../../../../../tasks/prd-ai-cost-engineer-mvp.md) 重写；V03 是规划 ID，GitHub 编号见 manifest。

## 目标与范围

- 候选条目与标准物料库匹配：名称、规格、别名精确匹配直接带出，模糊匹配返回排序候选，无匹配标记库外物料；停用物料不参与匹配。
- 清单与图纸两路候选同时存在时，输出共有项、清单独有、图纸独有的比对结果。
- 集中输出缺项、属性冲突、疑似重复、库外物料，支持修正、补录、合并、非标标记，以及有依据的单位换算。
- 存在未解决关键缺项时拒绝确认；确认后生成不可变标准清单版本，作为测算唯一输入，并保留确认人与时间。
