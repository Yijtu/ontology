## 目标与范围

- 从已确认标准清单逐行带出已确认执行标准参数作为基准参数；命中多条冲突规则时返回待人工选择，不自动选。
- 接收造价师填写的实际生产参数，校验其满足适用标准的允许偏差，不满足时阻断并返回原因。
- 按已确认工艺规则调用 V03-054 的 compute 操作，产出标准参数成本与实际生产成本两套逐行分项与合计；缺规则、缺价、缺参数的行单独标记，不进入合计。
- 多供应商价格由造价师显式选择；AI 不参与任何金额计算，输入输出形成不可变工件。

## 需求与规格

- [prd-ai-cost-engineer-mvp.md#us-014双成本测算计算引擎](../../../../../tasks/prd-ai-cost-engineer-mvp.md#us-014双成本测算计算引擎)
- [prd-ai-cost-engineer-mvp.md#4-功能需求](../../../../../tasks/prd-ai-cost-engineer-mvp.md#4-功能需求)

故事范围：C.US-014。逐项覆盖见[覆盖表](../../coverage.md)。

- C.US-014.AC-01 → C-T014-01：从已确认标准清单逐行带出适用标准参数（如板厚）作为基准参数。
- C.US-014.AC-02 → C-T014-02：造价师可填写实际生产参数；系统校验其满足适用标准的允许偏差，不满足时阻断并提示。
- C.US-014.AC-03 → C-T014-03：计算引擎按已确认工艺公式和企业价格计算分项与合计，产出**标准参数成本**和**实际生产成本**两套结果。
- C.US-014.AC-04 → C-T014-04：成本明细按费用构成展开（板材、表面处理、加工、配件、其他、运输，以确认的计价规则为准）。
- C.US-014.AC-05 → C-T014-05：缺少计算条件（无规则、无价、参数缺失）的行明确标记原因，不参与合计，也不与完整结果混淆。
- C.US-014.AC-06 → C-T014-06：AI 不参与金额计算；金额只由注册的确定性 compute 操作产出，输入输出形成不可变工件。
- C.FR-19 → C-F19：系统必须基于已确认清单、已确认标准规则、工艺公式与企业价格执行确定性计算，产出标准参数成本与实际生产成本两套结果。
- C.FR-20 → C-F20：系统必须校验实际生产参数满足适用标准允许偏差，不满足时阻断。
- C.FR-21 → C-F21：缺少计算条件的清单行必须明确标记原因，不得静默以零值参与合计。
