# V03-061：实现企业价格与市场参考价页面

阶段 B · frontend · P1 · 状态 planned · GitHub [#229](https://github.com/Yijtu/ontology/issues/229)

## 目标与范围

- 企业价格页支持录入、导入、查询、编辑，查看价格历史（旧值、新值、生效日期、操作人）。
- 市场参考价页支持维护品种、来源、日期、单位、价格。
- 成本复核视图并排显示企业价格、市场参考价与差异，明确市场价不参与测算。
- 导入失败行可定位，缺价提示给出补录入口。
