# V03-076：实现执行标准文档登记与标准规则服务

## 目标与范围

- 标准文档登记（编号、版本、原文文件）经 Core 导入并保留解析覆盖状态，可在线查阅。
- 人工录入标准规则：适用材质、产品类型、规格条件、参数名/值/单位、允许偏差；原文依据以 Core 文本 span 或表格行/单元格 span 固定，回看时重读核对。
- 规则有待确认/已确认状态，只有已确认规则可被测算读取；修改生成新版本，历史成本版本引用当次快照。
- 提供按物料条件查询适用规则的接口，命中多条冲突规则时全部返回并标记冲突。
