# V03-060：实现成本报价单资料、候选与标准清单确认页面

## 目标与范围

- 成本报价单页面展示单据编号、状态、上传文件列表（名称、大小、时间、解析状态），支持上传清单与图纸、回看和下载原件。
- 候选条目列表与原文对照；AI 识别结果标记“待确认”，数量待核实项高亮。
- 统一差异面板处理缺项、冲突、疑似重复、库外物料，提供清单与图纸比对视图、合并、补录、非标标记与单位换算编辑。
- 关键缺项未解决时“确认清单”不可用并说明原因；页面通过造价场景模块挂载。

故事范围：C.US-009、C.US-010、C.US-012。逐项覆盖见[覆盖表](../../coverage.md)。

- C.US-009.AC-01 → C-T009-01：项目下可创建成本报价单，有独立编号和状态（草稿/整理中/待测算/已确认/已冻结）。
- C.US-009.AC-02 → C-T009-02：支持上传材料清单（Excel/PDF）与图纸文件（PDF/PNG/JPG），可只传其中一类，也可两类都传。
- C.US-009.AC-03 → C-T009-03：文件列表显示文件名、大小、上传时间、解析状态。
- C.US-009.AC-04 → C-T009-04：文件读取失败或内容缺失时明确提示，不静默跳过。
- C.US-009.AC-05 → C-T009-05：原始文件可随时回看和下载；文件按项目隔离。
- C.US-009.AC-06 → C-T009-06：工程检查通过，并在浏览器核验。
- C.US-010.AC-01 → C-T010-01：Excel 清单经 Core 结构化解析，PDF 清单读取文本层，产出候选条目：原始名称、规格、数量、单位、来源位置（sheet/行号或页码）。
- C.US-010.AC-02 → C-T010-02：无文本层的 PDF 清单页提示“需按图纸方式解析或人工录入”，不冒称已解析。
- C.US-010.AC-03 → C-T010-03：候选条目以列表呈现，可与原始文件对照查看。
- C.US-010.AC-04 → C-T010-04：未提取到数量的条目标记“待核实”，不以零值或推测值填充。
- C.US-010.AC-05 → C-T010-05：解析失败的文件明确提示失败原因，候选清单中不出现该文件的幽灵条目。
- C.US-010.AC-06 → C-T010-06：每条候选保留来源引用，可回查原始内容。
- C.US-010.AC-07 → C-T010-07：工程检查通过，并在浏览器核验。
- C.US-012.AC-01 → C-T012-01：候选条目自动匹配标准物料库：精确匹配直接带出，模糊匹配给出候选供选择，无匹配标记“库外物料”。
- C.US-012.AC-02 → C-T012-02：清单与图纸两路候选同时存在时，提供比对视图（共有项、清单独有、图纸独有）。
- C.US-012.AC-03 → C-T012-03：集中呈现缺项、属性冲突、疑似重复、库外物料，支持修正、补录、合并、非标标记。
- C.US-012.AC-04 → C-T012-04：造价师可编辑数量、单位及单位换算；换算需有依据。
- C.US-012.AC-05 → C-T012-05：存在未解决的关键缺项时，“确认清单”不可用或确认时阻断。
- C.US-012.AC-06 → C-T012-06：确认后生成不可变的标准清单版本，作为测算唯一输入。
- C.US-012.AC-07 → C-T012-07：工程检查通过，并在浏览器核验。
- C.FR-12 → C-F12：系统必须支持上传材料清单（Excel/PDF）与图纸，解析失败必须明确提示。
- C.FR-15 → C-F15：当清单与图纸两路资料同时存在时，系统必须提供比对视图。
- C.FR-16 → C-F16：系统必须集中呈现缺项、冲突、疑似重复与库外物料，并支持修正、补录、合并、非标标记。
