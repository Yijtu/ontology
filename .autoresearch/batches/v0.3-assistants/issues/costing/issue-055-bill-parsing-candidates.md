# V03-055：实现材料清单解析与带来源的候选条目

## 目标与范围

- Excel 清单经 Core 结构化解析，PDF 清单读取文本层，产出候选条目：原始名称、规格、数量、单位，以及 sheet/行号或页码 locator。
- 无文本层的 PDF 页标记为需图纸方式解析或人工录入；解析失败的文件给出原因，候选池中不出现该文件的条目。
- 未提取到数量的条目标记“待核实”，不填零或推测值；数量与规格保留原始值和规范值。
- 候选条目可回查原始单元格或文本片段，并按项目、成本报价单隔离。
