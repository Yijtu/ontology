# V03-053：实现企业价格维护、导入与价格历史服务

阶段 B · backend · P1 · 状态 planned · GitHub [#221](https://github.com/Yijtu/ontology/issues/221)

执行工作线：feat/electrical-costing-poc；目标：feat/electrical-costing-poc。2026-10-14 按 [新 B PRD](../../../../../tasks/prd-ai-cost-engineer-mvp.md) 重写；V03 是规划 ID，GitHub 编号见 manifest。

## 目标与范围

- 实现企业价格的录入、Excel 导入、查询、编辑：品项、单价、计价单位、供应商、来源、日期、含税口径；导入复用 Core 结构化解析并逐行报告失败原因。
- 每次变更追加价格历史（旧值、新值、生效日期、操作人），不原地覆盖。
- 提供按物料和日期查询有效价格的接口：多供应商时返回全部候选供造价师选择，无有效价格时返回明确的缺价原因，不返回零价。
- 金额以十进制字符串存储和传递，拒绝浮点、指数与非法精度。
