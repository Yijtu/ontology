## 需求与规格

- [prd-ai-cost-engineer-mvp.md#us-003标准物料库维护](../../../../../tasks/prd-ai-cost-engineer-mvp.md#us-003标准物料库维护)

- [prd-ai-cost-engineer-mvp.md#4-功能需求](../../../../../tasks/prd-ai-cost-engineer-mvp.md#4-功能需求)

故事范围：C.US-003、C.US-004、C.US-005。逐项覆盖见[覆盖表](../../coverage.md)。

- C.US-003.AC-01 → C-T003-01：支持按名称、规格、分类、别名查询，以及新增、编辑、停用。
- C.US-003.AC-02 → C-T003-02：物料字段至少包含：分类、名称、材质、规格属性（如 200×100）、单位、别名列表。
- C.US-003.AC-03 → C-T003-03：物料可关联适用执行标准与工艺规则（US-004、US-005）。
- C.US-003.AC-04 → C-T003-04：支持 Excel 批量导入，报告成功和失败行数及失败原因；导入复用 Core 结构化解析，失败行定位到 sheet/行。
- C.US-003.AC-05 → C-T003-05：停用物料不出现在匹配候选中，历史项目引用不受影响。
- C.US-003.AC-06 → C-T003-06：工程检查通过，并在浏览器核验。
- C.US-004.AC-01 → C-T004-01：支持上传和登记标准文档（编号、版本、原文文件），可在线查阅；原文经 Core 导入并保留解析覆盖状态。
- C.US-004.AC-02 → C-T004-02：支持人工新增标准规则：适用材质、产品类型、规格条件、参数名/值/单位、允许偏差，以及原文依据。
- C.US-004.AC-03 → C-T004-03：原文依据以 Core 的文本 span 或表格行/单元格 span 固定；回看时重读原件并核对摘要，原件变化后依据显示失效。
- C.US-004.AC-04 → C-T004-04：规则有“待确认/已确认”状态，**只有已确认规则参与自动测算**。
- C.US-004.AC-05 → C-T004-05：规则修改生成新版本，历史成本版本仍引用当次确认的规则快照。
- C.US-004.AC-06 → C-T004-06：同一物料命中多条冲突规则时不自动选择，在测算条件确认页提示人工选择。
- C.US-004.AC-07 → C-T004-07：不包含 AI 自动提取规则。
- C.US-004.AC-08 → C-T004-08：工程检查通过，并在浏览器核验。
- C.US-005.AC-01 → C-T005-01：支持维护工艺规则：适用条件（物料分类、规格范围）、参数、公式、版本。
- C.US-005.AC-02 → C-T005-02：公式引用的标准参数取自 US-004 已确认规则，不重复维护。
- C.US-005.AC-03 → C-T005-03：规则变更保留版本，历史测算引用当次版本。
- C.US-005.AC-04 → C-T005-04：支持用样例数据对单条规则试算并显示结果。
- C.US-005.AC-05 → C-T005-05：MVP 只支持约定的 2–3 种计价规则；每种规则是一个经审查测试、注册到 Core 的版本化 compute 操作，页面只维护其参数，不提供任意表达式或脚本。
- C.US-005.AC-06 → C-T005-06：工程检查通过，并在浏览器核验。
- C.FR-3 → C-F03：系统必须支持标准物料的增删改查、停用与 Excel 批量导入，物料含分类、材质、规格、单位、别名。
- C.FR-4 → C-F04：系统必须支持标准文档登记与标准规则的人工录入，规则包含适用条件、参数值、单位与原文出处。
- C.FR-6 → C-F06：系统必须支持工艺规则的维护：适用条件、参数、公式、版本，并提供样例试算。
